# 版本卡 · `0.1.5-rc.2` → `0.1.6-alpha.2`

> 本卡只对 **`0.1.5-rc.2 → 0.1.6-alpha.2`** 这一个封闭走廊负责。上一个走廊（`0.1.3-alpha.1 → 0.1.5-rc.1`）由 `dsh-plugin-upgrade-015` 承担；本走廊是一个**新包**（`dsh-plugin-upgrade-016`），五条接缝与旧目录零交集，两包不共享任何 SEAMS 清单。
> 走廊方法论不变：走廊永不加宽，一个 hop 加一条接缝就是一个新包。

## 1. 这个跨度里什么会坏（全部是**静默**或**运行时**失效）

| 类 | 破坏 | 结果 |
|---|---|---|
| 槽删除 | `settings.plugin.item` → `plugins.item`（keyed→list） | 设置卡**静默消失**（`registry.ts` `spec===undefined return`） |
| 客户端 API 删除 | `ISessions.open/openSubagent/clear` → `retain/using/retainInfo` | 点会话/子代理跳转：响亮 TypeError 或吞错成错误字符串 |
| 状态字段删除 | `SessionListState.current` | 7 仓命中、3 仓功能瘫痪、4 仓 cast 结构面静默降级（tsc 抓不到） |
| 运行期竞态 | `agent/created` 串行派发 + 异步 apply 竞态 | 监听器抛错阻断创建；卸载窗口内 INACTIVE_EFFECT |
| 模型目录收缩 | 默认模型目录 4→2，未编目 id 透传 text-only | vision 档带图请求响亮抛 UNSUPPORTED_CONTENT，cheap 档静默 |

**为什么本地绿灯不可信**：已发布类型线把删除全部藏住（stale-type false green）；槽与状态删除没有别名、没有 deprecation 说明；两条运行期竞态任何 typecheck 都看不见。**本扫描器必要但不充分**：一个干净的扫描只证明「没有命中已知接缝」，不是「已适配」——写日志的仓需要 resume 往返，有 client 半边的仓需要真浏览器断言，所有仓需要真宿主冒烟。

## 3. E1 · `agent/created` 监听器抛错阻断创建（error）

- **证据**：A1 串行链已核实（方案 `[A02]`/`[A05]`；宿主 agent 创建在监听器链上串行派发，异常直接中断创建路径）。
- **改法**：监听器「绝不抛错 + 快速返回」——同步工作包 try/catch；重工作 `queueMicrotask`/`setImmediate` 或投递自有队列；副作用失败只记日志。
- **验证**：真宿主上创建 agent 不中断；监听器故意抛错 → 宿主创建仍成功（修复后回归锁）。

## 4. E2 · 异步 apply 竞态（error）

- **证据**：A02 统一修法已定案（方案 §2.3）——`register()` 返回值必须交给 `ctx.effect()`；首个 `await` 之后的注册在卸载窗口内必抛 `INACTIVE_EFFECT`（抛点 `fiber.ts` 已核实）；旧闭包继续生效（doublecheck `src/guard/index.ts:664` 为反例）。
- **改法**：一个 effect 持有注册 + 资源；一切 `ctx.effect/ctx.on/ctx.provide/ctx.plugin/*.register` 移到第一个 `await` 之前；删掉吞异常的 `.catch(()=>{})`。
- **验证**：G-9 关→开两次——贡献只出现一次、无 INACTIVE_EFFECT、无重复 audit。

## 5. E3 · 被删槽/状态键（error）

- **证据**：`settings.plugin.item` 删除（B1，`dsh-github/src/client.ts`、`dsh-ticktick/src/client/index.ts` 命中）；`SessionListState.current` 删除（B5，7 仓命中：composer-history/team-rooms/background-agents/budget/autotier/draw/mcp-panel）。
- **改法**：设置卡迁 `plugins.item`（list 槽，条目 `id`/`order`/`label`，props `{view:'summary'|'page'}`，不传 priority）；「当前会话」从槽标准 props `sessionId`/`useSessionStatus`/`retainedBy.mainView` 推导（上游 `ui-session` 是模式），保留 undefined 守卫。两仓的 `lib/client.js` 是已提交构建物 ⇒ 必须重建并提交。
- **验证**：`grep -n "settings\.plugin\.item"` 与 `list.current` 双零命中 + 真浏览器（设置卡出现）。

## 6. E4 · 被删客户端 API（error）

- **证据**：`ISessions` 删 `open/openSubagent/clear`（B2，session-pin `src/client.ts:405/430` 响亮 TypeError、background-agents `src/client/index.ts:227` try/catch 吞错、claude-move `client/client.js` 特性探测）。
- **改法**：`retain(id, { source })`（alpha.2 内置 `'controllerOperation' | 'gateway'`；返回 Disposable——面板持有时存下、卸载/关闭时 dispose，不持有则忽略返回值并注释）；特性探测 + 回退在保留旧 peer 带期间合法（扫描器降级为 review lead）。
- **验证**：tsc 对 alpha.2 类型面绿 + 真浏览器点击路径无 TypeError。

## 7. E5 · 被删模型字面量（error）

- **证据**：默认模型目录 4→2（C3；上游 `llm-deepseek/README.md:48` 原文：未编目 id 透传 text-only）；非测试区 3 仓引用被删 id（autotier 默认值、github `action.yml:39`、auto-review eval 配置）+ autotier README×5 与 8 个测试文件硬编码。
- **改法**：配置默认值与测试硬编码换成仍在册的模型 id；README 同步。
- **验证**：`grep -rn "deepseek-v4-flash\|deepseek-v4-vision-exp"` 零命中（测试区除外并记录）。
